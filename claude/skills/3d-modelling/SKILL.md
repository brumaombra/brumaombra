# 3D Modelling

Design every part as a native FreeCAD document generated by a Python script, so I can open and edit it in FreeCAD. When the part will be printed, also follow the `3d-printing` skill.

## Running FreeCAD

- Run the scripts with FreeCAD's command-line interpreter: `freecadcmd script.py` (`FreeCADCmd.exe` on Windows). If the environment's rules give a path, use it; otherwise look for it on the `PATH` and in the usual install folder, and ask me if you can't find it.
- While the script is the source (see below), it builds the whole part from scratch: create the document, the `Params` spreadsheet, and the Body, then `recompute()`, check the result, save the `.FCStd` with `saveAs()`, and export the STEP and STL files.

## FreeCAD structure

Follow the FreeCAD best practices, so the documents stay editable and don't break when changed:

- Part Design workbench: one Body per part.
- Every dimension lives in a `Params` spreadsheet, in named cells, with a short note on where the value comes from. Sketches and features read their sizes from it with expressions: no hard-coded numbers in the model.
- Sketches are fully constrained, and attached to the Body's origin planes or to datum planes, never to the faces of other features (FreeCAD 1.0 mitigates the topological naming problem, but face references can still break when an earlier feature changes).
- In scripts, select the edges for fillets and chamfers by their position or geometry, never by generated names like `Edge12`: those names change whenever an earlier feature changes.
- Give every object a clear name (`LidSketch`, `ButtonHolePocket`, not `Sketch001`).
- Check the fit in an assembly document with reference models of the other parts and boards, which are never printed.
- Before exporting, recompute and check: no object in error, a valid shape, one solid per part.

## Source of truth

- While we design together, the script is the source: it regenerates the `.FCStd`, STEP, and STL. If I change values in FreeCAD and commit the document, copy them back into the script before running it again.
- Once I say a design is final, the committed `.FCStd` becomes the source, and you edit it instead of regenerating it.

## Files

For each part, commit the script that generates it, the `.FCStd` document, and the exported STEP and STL files.
