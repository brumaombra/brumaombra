# Cloudflare R2

The project can upload files to Cloudflare R2. The API token is a network secret: the proxy adds it to every request to `api.cloudflare.com`, so you never see it and don't need it.

- Use the Cloudflare MCP to find all the info you need to upload the files. Ask me to confirm the bucket before the first upload of the session.
- Upload with `curl -s` straight from disk to that endpoint. Never upload through an MCP tool or read a file just to upload it: the content would go through the conversation and waste tokens.
- Never ask me for the token. If an upload returns `401` or `403`, stop and tell me: the network secret is missing or expired.
- Ask before overwriting or deleting existing objects.
